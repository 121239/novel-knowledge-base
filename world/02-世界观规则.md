# 世界观规则

## 基本规则

1. **现实世界**：1976年的中国，没有魔法、修仙、超能力
2. **金手指唯一例外**：只有主角有身体强化能力
3. **历史不能改变**：重大历史事件按真实时间线进行
4. **蝴蝶效应允许**：小人物命运可以改变

## 社会规则

1. **公社体制**：集体劳动，记工分
2. **物资配给**：粮食凭票供应
3. **婚姻制度**：一夫一妻制（多女主需要特殊设定解释）
4. **社会流动**：极度受限，农民基本不能进城

## 经济规则

1. **货币**：人民币，但农村以物易物为主
2. **物价**：一斤玉米面约几分钱，一条鱼可换2-3斤玉米面
3. **收入**：农民一年工分收入约几十元

## 创作规则

1. **不能出现超越时代的东西**
2. **不能出现不符合1976年社会逻辑的行为**
3. **人物的行为必须符合其身份和时代背景**
4. **幽默感来自时代反差，不是现代梗硬套**
